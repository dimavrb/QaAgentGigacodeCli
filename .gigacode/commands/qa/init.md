description: Подключить текущий проект к QA Agent extension и сохранить контекст приложения
---

Подключи текущий проект к установленному QA-пакету. Получи фактический
`package_root`, `package_version` и `project_tool` через MCP `qa_package_info`.
Определи абсолютный `project_root` из текущего рабочего проекта, а не из каталога
установки расширения. Прочитай `<package_root>/docs/EXTENSION_RUNTIME.md`.

Запусти `python3 "<project_tool>" init --project-root "<project_root>"`.
При несовпадении старого пути пакета сначала покажи пользователю старый/новый
путь и установи причину; `--rebind` применяй только для разрешённого переноса.
Не удаляй прежнее подключение `qa-agent/APP_COORDINATOR.md` автоматически.

Существующий `.qa-agent/APP_CONTEXT.md` сохрани. Для нового контекста изучи
правила приложения и укажи только подтверждённые факты. Неизвестное оставь
как `не настроено`; не спрашивай параметры Jenkins/ТестОпс до поручения готовить
эту инфраструктуру. Не устанавливай MCP, модель или авторизацию этой командой.

Выполни `/qa:doctor` и сообщи версию, изменённые файлы и пределы проверки.
`configured` подтверждает локальное подключение файлов, а не готовность стенда.
