# QA-пакет 2.2.1 — сохранённые задания и восстановление

Read-only MCP `qa_tasks_list` и `qa_task_get` читают проектные реестры
`.qa-agent-state/tasks/*/task.json`. Список незавершённых заданий имеет страницы,
фильтр истории и предупреждения о повреждении/дубликатах. Чтение выбранного
ID возвращает владельцев, критерии, вопросы, ссылки и записанные hashes материалов.
Tokens передачи и сырые события не выдаются; ссылки не исполняются и не читаются.

`/qa:tasks` показывает задания, `/qa:resume <ID>` восстанавливает выбранное.
Пустая `/qa` предлагает выбор либо новую цель. Восстановление по-прежнему требует
проверки владельца, условий, артефактов и expected-revision. MCP не запускает
исполнителей, не принимает результат и не снимает отмену.

[TASK_STORAGE.md](TASK_STORAGE.md) закрепляет пути новых планов, каталогов,
реестров, расследований и доказательств. Старые пути не переносятся автоматически;
Git не синхронизирует локальные состояния исполнения.

## Проверки и ограничения

```bash
python3 -m unittest discover -s tests -p test_qa_tasks.py -v
python3 -m unittest discover -s tests -p test_extension_project.py -v
python3 -m unittest discover -s tests -v
python3 scripts/package_agent.py --output-dir dist/release-2.2.1 --date 2026-10-14
python3 scripts/package_agent.py --verify dist/release-2.2.1/qa-agent-2.2.1.zip
```

Проверяются реальные локальные реестры, read-only снимки, владельцы, фильтрация,
страницы, повреждение, неоднозначные ID, закрытые токены, FIFO/симлинки и смена
родителя между проверкой и чтением. Stdio сохраняет работоспособность после
глубокого/длинного JSON. Живой GIGACODE отсутствует: выбор/продолжение моделью
и загрузку пяти команд/tools нужно подтвердить пилотом.

Предыдущие замечания промышленного ревью к проверке/откату автообновления,
конкурентной инициализации/перепривязке и чтению привязки launcher требуют
отдельных исправлений; этот выпуск не объявляет промышленную приёмку закрытой.
