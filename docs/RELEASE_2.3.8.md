# QA-пакет 2.3.8 — универсальный навык Jira и приёмка заглушек

В поставке шесть skills. Новый
[jira-defect-creator](../.gigacode/skills/jira-defect-creator/SKILL.md)
оформляет дефекты в разных Jira-проектах. Переносится процесс; поля, опции,
типы задач, разметка, JQL и направление связей измеряются для каждого проекта
и коннектора. Значения заказчика не становятся доказанными без проверки.

Навык включает настройку проекта, создание/дополнение, dry-run, обязательный
поиск/чтение дублей, сводный чек-лист, проверку payload и сохранённых полей,
восстановление, частичные результаты, журнал и накопление ошибок.
Профили и состояние хранятся вне поставки; секреты не включаются в артефакты.

Python-helper из навыка не подключается к Jira: проверяет allowlist путей,
типы, exact wire-значения, обязательные/AUTO-поля, summary/description,
срок/идентичность профиля и неизменность хеша. Он не удостоверяет полноту поиска,
происхождение замеров, внутреннюю MCP-схему свободных объектов или согласие.
Эти проверки остаются обязанностью исполнителя.

Managed-публикация сохраняет JIRA_PUBLICATION.md: независимый scope, принятый
defect_confirmed, полный поиск, один create/одна попытка, квитанция и readback.
Unknown не лечится повтором create или новым gateway. Вложения, дополнения
и связи требуют отдельных назначений; возможности standalone не расширяют scope.

Инструкция обновления — [UPGRADE_2.3.8.md](UPGRADE_2.3.8.md).
Исторические отчёты, протоколы и хеши не изменяются. Навык создан в репозитории;
глобальная установка, подключение и запись в Jira не выполняются этим выпуском.

Параллельные изменения этого выпуска усиливают приёмку заглушек: независимый
stub_assignment, замороженные первичные наблюдения и before-снимок, проверку
времени и предметный контекст reviewer. Подробности — [STUBS.md](STUBS.md).

## Проверки

Локальные проверки прединспекции и полный unittest-набор запускаются командами:

```bash
python3 -m unittest discover -s tests -p test_jira_defect_skill.py -v
python3 -m unittest discover -s tests -v
python3 scripts/package_agent.py --output-dir /tmp/qa-agent-2.3.8 --date 2026-10-15
python3 scripts/package_agent.py --verify /tmp/qa-agent-2.3.8/qa-agent-2.3.8.zip
```

Синтетические fixtures проверяют локальную логику, не Jira или качество живой
модели. Для промышленной готовности нужны настройка конкретного проекта,
dry-run на реальном тексте и отдельно разрешённые живые проверки.

Навык прошёл штатный quick_validate.py, проверку внутренних ссылок и 18 локальных
тестов helper. В совместном рабочем каталоге версии 2.3.9 полный прогон завершён:
**942 теста, OK**. Сборка и проверка manifest подтверждают включение семи файлов
навыка без runtime-состояния. Учебный dry-run —
[references/dry-run.md](../.gigacode/skills/jira-defect-creator/references/dry-run.md).
