# QA-пакет 2.3.1 — отбор и понятность ручных кейсов

Первая итерация навыка пригодна для тестовой задачи команды:

- Перед шагами автор проверяет пользу, достижимость в выбранном канале и
  добавленное покрытие. Решения и причины остаются в плане по
  [TEST_CASE_SELECTION.md](TEST_CASE_SELECTION.md).
- Простые наблюдения встраиваются в связанный сценарий; права, границы,
  разные уровни проверки и редкие существенные риски сохраняются.
- По [TEST_CASE_STYLE.md](TEST_CASE_STYLE.md) подготовка, действия и ожидания
  должны быть подтверждены и понятны исполнителю без участия в обсуждении.
- Контекст проекта описывает способы подготовки и наблюдения. Неизвестное
  блокирует проектирование, временная недоступность известного способа — исполнение.
- Bare-автор получает новые инструкции в замороженном контексте. Новое назначение
  reviewer ручного каталога явно передаёт стандарты через instruction_paths.
- [TEST_CASE_PILOT.md](TEST_CASE_PILOT.md) содержит назначение для реальной задачи;
  отдельный учебный набор включает 15 кандидатов и ориентиры оценки.

События, MCP, schema_version: 1, stable scenario_id и преобразование JSON → Allure
сохраняются. Автоматическая смысловая фильтрация валидатором, барьер публикации
и новые TMS-поля в эту итерацию не входят. Содержательное принятие выполняется
по источникам; автоматические проверки не доказывают качество модели.

## Проверка поставки

Локально прошли 693 теста в повторном полном прогоне, 23 проверки контекста,
5 проверок каталога и 16 проверок Allure-преобразования. В первом полном прогоне
сбоили два существующих теста обсуждения ревью; все 26 тестов этого механизма
прошли отдельно, затем весь набор прошёл без изменений его кода. Логи первого,
адресного и повторного прогонов сохранены вне поставки.

```bash
python3 -m unittest discover -s tests -p test_context_assembly.py -v
python3 -m unittest discover -s tests -p test_test_cases.py -v
python3 -m unittest discover -s tests -p test_manual_allure.py -v
python3 -m unittest discover -s tests -v
python3 scripts/package_agent.py --output-dir dist/release-2.3.1 --date 2026-10-14
python3 scripts/package_agent.py --verify dist/release-2.3.1/qa-agent-2.3.1.zip
```

Учебные примеры проверяют совместимость каталога и преобразования, а реальную
пользу навыка оценивает пользователь на GIGACODE и задаче своего продукта.
Пилот на настоящем GIGACODE/TestOps и промышленная приёмка защиты обновления из
2.3.0 остаются отдельными этапами. Обновление — [UPGRADE_2.3.1.md](UPGRADE_2.3.1.md).
