# QA-пакет 2.3.10 — явное подключение ролей к проекту

В целевой установке пользователя глобальный extension установлен, но QA-роли
отсутствуют в `/agents manage`. Документация GIGACODE заявляет обнаружение
агентов активного extension; манифест QA-пакета уже указывает каталог с 14 ролями.
Причина расхождения с конкретной сборкой CLI в этой среде не установлена.

Для такого случая добавлен `scripts/qa_project_agents.py`: по умолчанию
показывает план, с `--apply` добавляет недостающие роли в `.gigacode/agents`
подключённого проекта. Требует совпадения привязки с корнем и версией пакета.
Другие файлы проекта, пользовательские настройки и registry не меняются.

Идентичные роли сохраняются; отличающиеся имена дают конфликт до начала записи.
Нет режима force. Симлинки отклоняются, конкурентно созданный файл сохраняется.
При ошибке записи часть отсутствующих ролей может быть уже опубликована;
после проверки состояния повторный запуск продолжит установку.

Doctor сравнивает проектные QA-роли с текущим пакетом и сообщает отличия через
`project_agent_copies`. Локальные адаптации рассматриваются отдельно; наличие
отличий не является разрешением их заменить. Native updater не синхронизирует
эти копии. Init сохраняет контракт трёх проектных файлов, подключение ролей —
отдельная команда. Новая утилита входит в release preflight/import probe.

Инструкции — [EXTENSIONS.md](EXTENSIONS.md#если-агенты-extension-отсутствуют-в-agents-manage),
обновление — [UPGRADE_2.3.10.md](UPGRADE_2.3.10.md).

Локальные проверки:

```bash
python3 -m unittest discover -s tests -p test_project_agents.py -v
python3 -m unittest discover -s tests -p test_extension_project.py -v
python3 -m unittest discover -s tests -p test_auto_update.py -v
python3 -m unittest discover -s tests -p test_update_hardening.py -v
python3 -m unittest discover -s tests -v
```

Результат: 9 тестов новой утилиты, 24 теста привязки/MCP, 26 тестов
автообновления и 18 тестов защиты/отката — OK. Полный набор: 952 теста, OK.
Тесты процессов и локальных серверов выполнены вне песочницы, блокирующей `ps`.
ZIP версии 2.3.10 с 498 файлами проверен по манифесту.

Локальная установка файлов не подтверждает загрузку или вызов агентов живым
GIGACODE. В новой сессии целевой сборки проверьте `/agents manage`, вызов роли
и возврат координатору. `live_agents_verified` остаётся false до такой проверки.
