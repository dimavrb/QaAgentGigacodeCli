# Обязательный минимум подготовки данных

Применяй к новой/изменённой подготовке. Подробности TEST_DATA.md читай по задаче, не целиком. Для новых назначений qa-test-data-builder действует DATA_READINESS.md: независимый scope, структурированные verified_properties и проверка текущей доступности. Качество набора и доказательства сохраняй также в существующем артефакте качества.

1. Определи scenario_id, источник правила, свойства и связи. Неизвестное правило уточни; независимую часть продолжай.
2. Для каждой записи объясни назначение и обнаруживаемую ошибку. Оставь минимальный набор с нужными контрпримерами; если ожидается объект, assert должен отклонять пустую выдачу.
3. Переиспользуй фабрику/фикстуру проекта, сохраняя бизнес-инварианты. Подготовка не выполняет тестируемое действие вместо теста.
4. Значимые значения задавай явно. Изолируй изменяемые данные по run/worker/test/attempt. Общие справочники проверяй; общее изменяемое состояние восстанавливай либо разделяй.
5. При неоднозначном создании проверь фактическое состояние до повтора. Для случайного набора сохрани seed и значения, для времени — момент/зону; готовность ожидай по условию с лимитом, не sleep.
6. Проверь каждое обязательное свойство, связь и видимость для нужной роли по data_assignment; сохрани actual_result, время и доказательства каждого requirement_id. Рецепт и успешное создание не подтверждают готовность без проверки; неподтверждённую часть сохрани ограничением/блокером. Данные должны оставаться доступными зависимому исполнителю в согласованном окне; очищенный набор не готов.
7. Регистрируй созданные ID сразу. Очищай только свои ресурсы в порядке зависимостей при частичном сбое и падении теста; ошибку очистки сохраняй отдельно. Учти остатки после остановки процесса и ограничения удаления. Не сбрасывай общую БД и не меняй production.
8. В артефакте: назначение записей, рецепт, изоляция, готовность и очистка, фактические доказательства/ограничения. Исключи секреты и реальные персональные данные. Различай проверку кода, синтетического примера и стенда.
