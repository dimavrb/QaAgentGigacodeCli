# QA-пакет 2.3.9 — область подключения и переустановка

Для подключения только к одному проекту уточнён порядок использования его
`.gigacode` и `GIGACODE.md` по [IMPORT_INTO_APP.md](IMPORT_INTO_APP.md).
Официальная документация подтверждает проектные роли, skills и команды.
Область установки native extension в этой среде не подтверждена: cwd и локальный
источник install не заменяют проверку `--help` конкретной сборки. Возможность
включения только в workspace также не означает отдельную версию для проекта.
В EXTENSIONS.md добавлен разбор project scope по документации и исходникам
Qwen Code: cwd передаётся менеджеру как workspace activation при общем
пользовательском хранилище. Аналогичная возможность GIGACODE не заявлена без
проверки его менеджера; дополнительных runtime/backend в пакет не добавлено.

В целевой установке пользователя `gigacode extensions update qa-agent`
требует сначала uninstall. В инструкцию добавлен порядок переустановки:
сохранить прежний пакет и адаптации, остановить активную работу, удалить
расширение штатным менеджером и установить из отдельного локального clone.
После установки проверяются версия, путь, проектная привязка и новая сессия.

Автообновление сохраняет исходный ответ CLI. При требовании uninstall показывает
подсказку о ручной переустановке; pending, recovery snapshot и блокировка
незавершённой активации сохраняются. Автоматического uninstall нет.
После ручной установки в прежний путь `qa-start --update-only` сверяет
содержимое и завершает pending без повторного вызова update.

Инструкция перехода — [UPGRADE_2.3.9.md](UPGRADE_2.3.9.md), подробный порядок —
[EXTENSIONS.md](EXTENSIONS.md#ручная-переустановка-если-update-требует-uninstall).
Исторические релизы, архивы, протоколы и хеши сохраняются.

Локальные проверки:

```bash
python3 -m unittest discover -s tests -p test_auto_update.py -v
python3 -m unittest discover -s tests -p test_update_hardening.py -v
python3 -m unittest discover -s tests -v
```

Результат: 26 тестов автообновления, 17 тестов защиты/отката и полный набор
из 942 тестов — OK. Прогоны выполнены вне песочницы: запрет `ps` внутри неё
блокировал проверку активных процессов. ZIP с 494 файлами проверен по манифесту.

Фикстуры проверяют отказы и восстановление локальной логики; GIGACODE в этой
среде отсутствует. Фактические uninstall/install, registry и сохранность
настроек расширения требуют проверки на целевой сборке CLI.

В текущий пакет также входят [проверки передачи заглушек](STUBS_HANDOFF_REVIEW.md):
замороженный stub_assignment до handoff, запрет будущих наблюдений, первичные
readback/пробы/before-снимки в хешах реестра и согласованный artifact_base.
Исторические наборы хешей не мигрируются; configure_only не открывает прогон продукта.
