# QA-пакет 2.3.5 — HTML-отчёт настройки стенда

После содержательного принятия отчёта qa-test-env-configurator реестр создаёт
`result.environment.html`. Это самостоятельная страница со статусом стенда,
версией, итогом настройки, результатом каждого пункта админгайда, действиями,
ожиданиями и наблюдениями, временем, ссылками на доказательства, блокерами,
ограничениями и оставшимися вопросами. Работает для ready, partial и blocked.

Payload.open_questions хранит вопросы, их влияние на готовность, point_ids и
scenario_ids. Открытый blocking-вопрос запрещает полную готовность. Решённые
вопросы требуют resolution/decision_source и не входят в оставшиеся. Для
ответов используется существующая форма QUESTIONS_UI.md; отчёт фиксирует
принятую версию и сам не изменяет ответы или статус стенда.

presentation содержит путь и хеш HTML, вид документа и хеш исходного отчёта;
ссылка доступна через CLI и qa_task_get. Координатор открывает HTML-панель или
браузер и возвращает страницу пользователю вместе с JSON. Ошибка сборки
сохраняется как needs_attention, принятие JSON остаётся действительным.
Старые источники и существующие чужие файлы не перезаписываются. Страница
не загружает внешние скрипты или шрифты, пользовательский текст экранируется.

Контракт — [ENVIRONMENT_READINESS.md](ENVIRONMENT_READINESS.md), пример —
[environment-readiness](../examples/environment-readiness/README.md),
обновление — [UPGRADE_2.3.5.md](UPGRADE_2.3.5.md).

## Проверки

Полный набор: **853 теста, OK**, включая 17 новых проверок HTML-отчёта:
автоматическая публикация после принятия, ready/partial/blocked, отсутствие
гайда, открытые/решённые/неуказанные вопросы, запрет блокирующего вопроса при
готовности, привязка вопросов к пунктам/сценариям, ссылки на источники,
изменённые доказательства, идемпотентный повтор, защита файлов и symlink,
экранирование, безопасная замена шаблона, CLI и ссылки в реестре/MCP.
Существующие 20 тестов HTML-планов прошли без регрессии.

Синтетическая страница с невыполненным пунктом и блокирующим вопросом открыта
и визуально проверена во встроенном браузере через локальный HTTP-просмотр.
Проверены статус, счётчики, вид вопроса, карточки пунктов и переход к вопросам.
Это проверка представления и локального протокола; реальный стенд и живой
GIGACODE не запускались.

```bash
python3 -m unittest discover -s tests -p test_environment_html.py -v
python3 -m unittest discover -s tests -v
python3 scripts/package_agent.py --output-dir /tmp/qa-agent-2.3.5 --date 2026-10-15
python3 scripts/package_agent.py --verify /tmp/qa-agent-2.3.5/qa-agent-2.3.5.zip
```
