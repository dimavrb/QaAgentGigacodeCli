# QA-пакет 2.3.13 — проектная установка без QA MCP-сервера

Скрипты, инструкции, роли и навыки устанавливаются внутри приложения. Установщик
qa_install.py копирует проверяемую поставку в .qa-agent/package, профиль в .gigacode,
обновляет управляемый блок GIGACODE.md и публикует переносимый install.json последним.
Повтор идемпотентен. Весь план проверяется на конфликты до записи, при ошибке
восстанавливаются прежние файлы; аварийное прерывание требует --recover --apply.

Изменённые пользователем файлы не перезаписываются. Контекст, настройки, задачи,
артефакты и история остаются вне заменяемой папки. Пакет и профиль можно коммитить
в Git. Абсолютные пути вычисляются при запуске, установка переносится в другой
checkout. Старые задачи с frozen-путями не переписываются.

QA MCP-сервер удалён. Новый CLI qa_task_create.py создаёт стандартный реестр по
согласованному файлу критериев, идентичный повтор сохраняет прежнюю ревизию.
Остальные операции используют существующий manage_task.py и локальные валидаторы.
qa-start в проекте проверяет комплект и удерживает блокировку сессии без автообновления.
Внешние системы и scoped gateway изолированных workers не изменяют свои полномочия.

Порядок установки и восстановления — PROJECT_INSTALLATION.md, переход — UPGRADE_2.3.13.md.
Локальные проверки не подтверждают live-поведение GIGACODE; CLI в среде разработки отсутствует.
Полный набор `python3 -m unittest discover -s tests -v`: 1006 тестов за 387,995 с,
OK. Целевые проверки установки: 17 тестов, OK; проверены обновление всего профиля,
конфликты, перенос checkout, блокировка сессии, rollback и аварийное восстановление.
Полный прогон выполнен с доступом к ps и локальным HTTP-фикстурам, необходимым
процессным тестам. Локальные фикстуры не подтверждают качество живой модели.

ZIP с 545 файлами проверен по PACKAGE_MANIFEST.json. Установка из распакованного
ZIP в чистый временный проект: installed; повтор: unchanged, 0 изменений.
Локальные init, create, идентичный retry и список задач прошли; настройки приложения
сохранились. Doctor подтвердил пакет/профиль; единственная failed-проверка —
отсутствующий GIGACODE CLI. Проверка модулей в отдельном интерпретаторе и
согласованность корневых ресурсов с .gigacode также прошли.
