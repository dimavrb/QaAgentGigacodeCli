# Обновление QA-пакета до 2.3.13

Полный порядок — [PROJECT_INSTALLATION.md](PROJECT_INSTALLATION.md).
Возьмите новый проверенный выпуск вне приложения и запустите его qa_install.py
с --project-root, затем --apply. В проекте всегда одна версия. Изменённые локально
управляемые файлы требуют разбора до обновления всего комплекта.

Завершите активные назначения/managed-планы и закройте GIGACODE. Контекст,
история задач и доказательства сохраняются. Прерванную установку восстановите
тем же установщиком с --recover --apply. Затем повторите обновление и doctor.

Пакет, install.json, профиль и управляемый блок GIGACODE.md коммитьте одним PR.
На других checkout выполняйте git pull только между сессиями, затем doctor.
Старые frozen-планы и абсолютные пути задач автоматически не мигрируют.
Переход с глобального extension — [UPGRADE_2.3.13.md](UPGRADE_2.3.13.md).
