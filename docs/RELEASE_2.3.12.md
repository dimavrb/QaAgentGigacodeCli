# QA-пакет 2.3.12 — корневые ресурсы native extension

В целевой сборке GIGACODE расширение подключало контекст и MCP, но не находило
QA-роли и навыки: discovery читает только корневые `agents/`, `skills/`, `commands/`
и игнорирует одноимённые поля путей в манифесте. Раньше ресурсы находились
только в `.gigacode/…`.

В 2.3.12 корневые каталоги содержат 14 ролей, 6 навыков с references/scripts и
5 команд. `.gigacode/…` остаются исходниками для проектного режима, прежних
путей контекста и предвалидации обновлений кодом 2.3.11. Поля путей манифеста
сохранены для старого валидатора; native discovery использует стандартные каталоги.

`scripts/extension_resources.py --apply` регенерирует корневые копии из исходников;
вызов без флага проверяет без записи. Проверки пакета и метаданных отклоняют
отсутствующие, дополнительные или изменённые экспорты. Новые каталоги включены
в ZIP, SHA-256 manifest, предвалидацию обновлений и проверку установленного пакета.
История управляемых проектных ролей, pending и сохранённые доказательства не меняются.

Переход и проверка новой сессии — [UPGRADE_2.3.12.md](UPGRADE_2.3.12.md), устройство
раскладки — [EXTENSIONS.md](EXTENSIONS.md#раскладка-ресурсов-расширения).

Команды локальной проверки:

```bash
python3 scripts/extension_resources.py
python3 -m unittest discover -s tests -p test_extension_resources.py -v
python3 -m unittest discover -s tests -p test_package_agent.py -v
python3 -m unittest discover -s tests -p test_extension_project.py -v
python3 -m unittest discover -s tests -p test_auto_update.py -v
python3 -m unittest discover -s tests -p test_update_hardening.py -v
python3 -m unittest discover -s tests -v
```

Результат: 7 новых проверок экспорта/discovery, 5 проверок упаковки и 24 проверки
привязки/MCP — OK. Полный набор из 983 тестов прошёл за 379,613 с, включая 26 тестов
автообновления и 18 тестов защиты/восстановления. Пример test-data также прошёл.
Старый trusted preflight 2.3.11 принимает новую поставку; новый валидатор принимает
прежнюю. Отдельный переход кодом обновлятора 2.3.11 с локальным установщиком-фикстурой
завершился как `updated`, а recovery-журнал содержит новые корневые ресурсы.
ZIP версии 2.3.12 с 539 файлами проверен по манифесту.

Тест discovery воспроизводит сообщённый способ поиска по стандартным каталогам
и проверяет распакованный ZIP без полей путей манифеста. Он не запускает настоящий
загрузчик GIGACODE. Живую загрузку ролей, skills и вызов субагента нужно проверить
в новой сессии целевого CLI; локальные файлы не подтверждают качество модели.
