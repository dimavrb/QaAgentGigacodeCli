# Обновление QA-пакета до 2.1.2

Текущая поставка содержит профиль GIGACODE CLI и общий контракт headless-json-v1.
Прежние релизные документы и протоколы остаются в истории Git. Рабочие архивы,
registry, benchmark и journals сохраняйте отдельно: их содержимое и hashes
не изменяются заменой строк или переименованием полей.

Обновляйте весь пакет и подключённые копии ролей/skills/команды. Общие правила —
`docs/COORDINATOR.md`, точка входа — `GIGACODE.md`, профиль — `.gigacode/`,
настройки запуска — `qa-runtime.json`. Перенос в приложение — [IMPORT_INTO_APP.md](IMPORT_INTO_APP.md).

Измерения для сравнения должны содержать явный backend, cli_version и
cli_executable_sha256. Старый формат без этих полей отклоняется; используйте
исходную версию пакета для его аудита. Не дополняйте неизвестное выдуманными
значениями и не приписывайте старые результаты новой среде.

После обновления выполните локальные тесты и preflight по [RUNTIMES.md](RUNTIMES.md).
При изменении инструкций создайте новый managed-план после проверки внешних
действий/readback. Runtime-состояния и доказательства не заменяйте файлами поставки.
Проверка memory/ролей/skills/команды и live-совместимости выполняется отдельно.
