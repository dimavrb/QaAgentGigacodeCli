# Контекст GIGACODE и переносимые инструкции

`GIGACODE.md` импортирует только короткие общие правила `docs/COORDINATOR.md`.
Предметные стандарты читаются по роли и этапу. Managed-сборщик передаёт их снимки
явно, хранит hashes и не обрезает доказательства ради лимита.

Настройка `tools.eager` не входит в профиль: её совместимость и эффект
в GIGACODE не подтверждены. Поставка содержит документированную секцию MCP,
без изменения auth, модели и политик разрешённых действий.

В именованных субагентах сохранены явные allowlist tools там, где они были заданы;
роли инфраструктуры наследуют инструменты установки. Сверяйте имена по `/tools`
в своей сборке. При недоступном tool возвращайте конкретный блокер. Не расширяйте
allowlist для обхода ограничения и не снимайте ограничения целевого проекта.

Для контроля стоимости используйте `/context detail` в новой сессии и одинаковые
контрольные задачи. Измеряйте фактические токены, время, качество и все повторы;
число символов не является токенами. Сокращение файла не доказывает экономию.

При отдельном runner frontmatter не ограничивает весь headless runtime. Контракт,
preflight и пределы изоляции описаны в [RUNTIMES.md](RUNTIMES.md). Успешный preflight
не является проверкой поведения флагов или live-приёмкой.
