# Обновление до 2.3.5

1. Завершите активные назначения и обновите пакет целиком по EXTENSIONS.md.
   Сверьте VERSION и gigacode-extension.json: 2.3.5. Личные настройки, реестры,
   доказательства и прежние HTML сохраняются вне поставки.
2. В новой сессии проверьте qa_package_info, `/qa:init` и `/qa:doctor`. Для новых
   запусков создавайте managed-планы с актуальными инструкциями и хешами.
3. Настройщик передаёт open_questions по ENVIRONMENT_READINESS.md или явно [].
   Координатор принимает точный JSON, затем проверяет presentation: ready
   означает готовый HTML, needs_attention содержит причину ошибки представления.
   Статус готовности стенда выводится отдельно внутри документа.
4. Для уже принятого неизменённого отчёта нового протокола можно запустить:

```bash
python3 scripts/build_environment_html.py --state /absolute/task.json --request-id env-1
```

При конфликте существующего файла используйте отдельный --output; чужие файлы
не заменяются. Не дописывайте вопросы в принятый JSON: исправленный отчёт
получает новый request_id и result_path. Отсутствующие вопросы в старом отчёте
показываются как неизвестные; готовность старого формата без админгайда не
подтверждается HTML. Пересчёт исторических хешей не требуется.

После генерации откройте presentation.path и передайте ссылку пользователю.
При копировании страницы сохраняйте доступность её локальных источников и
доказательств. Ответы собираются штатной формой и применяются отдельно.
