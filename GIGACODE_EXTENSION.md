# QA Agent

Проектная установка — `docs/PROJECT_INSTALLATION.md`. QA MCP-сервер отсутствует.
Если `.qa-agent/install.json` ещё нет, предложите `/qa:init`: эта команда сама
получает исходник в проектную bootstrap.local и выполняет первую установку.
Не просите пользователя вручную запускать Python из внешнего extension.
Если пакет уже установлен, /qa:init использует его локальные init/doctor без
замены версии. При повреждённой/незавершённой установке сначала рассмотрите ошибку.

В проекте package_root = <project_root>/.qa-agent/package. Проверяйте install.json
и локальный scripts/qa_project.py doctor, затем используйте координатор из этого
пакета. После первой установки откройте новую сессию для загрузки проектных ролей.
Глобальный профиль не является источником исполняемых Python-файлов для QA-работы.
Внешние соединения и полномочия на изменения настраиваются отдельно.
