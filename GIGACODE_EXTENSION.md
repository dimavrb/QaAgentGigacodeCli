# QA Agent

Основной способ подключения — проектная установка по `docs/PROJECT_INSTALLATION.md`.
QA MCP-сервер в этом выпуске отсутствует. Если активировано native-расширение,
само включение профиля не создаёт проектную копию Python. До QA-работы установите
полный пакет из обычного терминала и отключите дублирующий глобальный профиль.

В проекте package_root = <project_root>/.qa-agent/package. Проверьте install.json
и локальный `scripts/qa_project.py doctor`, затем используйте инструкции
`docs/COORDINATOR.md` из этого пакета. При отсутствии проектной установки не
запускайте Python из внешнего extension. Личные соединения браузера/Jira
настраиваются отдельно; установка не даёт полномочий на внешние изменения.
