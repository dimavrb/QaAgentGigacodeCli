# Учебные требования

## R-1
Фильтр «Оплачен» показывает все оплаченные заказы текущего пользователя, сохраняя их ID, и исключает его неоплаченные заказы. В учебной фикстуре у пользователя только ORDER-PAID («Оплачен») и ORDER-NEW («Новый»).

## R-2
Вход с неверным паролем отклоняется. Решение для примера принято в ответе Q-1.
