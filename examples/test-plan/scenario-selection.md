# Выбор сценариев до подробных шагов

Самостоятельный синтетический пример. Его требования и ID не дополняют каталоги `cases-v*.json` и не описывают реальное приложение.

## Источники и область

- R-A: фильтр «Оплачен» оставляет в выдаче только оплаченные заказы.
- R-B: если совпадений нет, выдача пуста; заказы других статусов не подставляются.
- R-C: пользователь видит только свои заказы, в том числе после фильтрации.

Область: R-A, R-B, R-C. Согласованный объём не включает исследование больших наборов данных. Ожидание по скорости в этом примере не задано.

## Ранние кандидаты

| ID | Критерий и возможная ошибка | Отличие и решение |
| --- | --- | --- |
| C-01 | R-A: выдача содержит заказ другого статуса | Свои заказы двух статусов; оставить |
| C-02 | R-A: заказ другого статуса остаётся в выдаче | Условия, действие и наблюдаемый результат эквивалентны C-01; предложить объединение |
| C-03 | R-B: при отсутствии совпадений показаны неподходящие заказы | Пустой результат — отдельный класс данных; оставить |
| C-04 | R-C: выдача содержит чужой оплаченный заказ | Другой владелец при подходящем статусе; отдельная проверка доступа, оставить |
| C-05 | Исследование времени ответа на большом объёме | Дополнительное исследование; не включать в текущий обязательный набор. Без источника ожидания не оформлять кейс с вымышленным пределом скорости |

Координатор проверяет предложение `C-01 + C-02 → C-01`: сохраняются R-A, класс данных и обнаруживаемая ошибка. C-03 и C-04 похожи по действию, но проверяют разные ошибки; объединять их только ради сокращения числа кейсов нельзя.

## Выбранный набор после оценки координатором

| ID | Набор и критерий | Возможная ошибка и отличие | Приоритет и причина |
| --- | --- | --- | --- |
| C-04 | Обязательный, R-C | Чужие данные; отдельное правило доступа | Высокий: раскрытие данных другого пользователя |
| C-01 | Обязательный, R-A | Примесь другого статуса; смешанный состав своих заказов | Средний: недостоверная выдача |
| C-03 | Обязательный, R-B | Подмена пустого результата; отсутствие совпадений | Средний: недостоверная выдача при отдельном условии |

Координатор подтвердил, что C-05 остаётся за пределами текущего объёма: поведение на больших наборах пока не исследуется. Ограничение сохраняется в плане, исследование не считается выполненным. В реальной задаче такое решение нельзя приписывать координатору без подтверждения.

При нехватке времени первым идёт C-04, затем C-01 и C-03. Готовность одного C-04 не означает `plan_ready`. Подробные шаги пишутся только после выбора; история предложения C-02 сохраняется, отдельный дублирующий кейс не создаётся.
