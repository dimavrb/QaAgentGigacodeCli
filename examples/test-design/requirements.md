# Синтетические правила просмотра заказа

Это учебная модель, не требования приложения. Реальные URL, данные и продуктовые действия отсутствуют.

## access

R-1: пользователь user получает содержимое только собственного заказа. Чужой заказ не раскрывается. Правило одинаково для UI и API.

R-2: admin получает содержимое собственного и чужого заказа. Правило одинаково для UI и API.

## clients

R-3: учебный UI проверяется в chrome и firefox. API-клиент работает без браузера, обозначение none. browser в этой модели описывает способ запуска, а не HTTP-заголовок. Значения ui/none и api/chrome или api/firefox не являются реализуемыми клиентами данного учебного набора.

## lifecycle

R-4: повторный просмотр не изменяет владельца или состояние заказа. Это свойство применимо ко всем разрешённым просмотрам; запрещённый просмотр также не изменяет заказ.

R-5: переход из состояния «Оплачен» в «Отменён» действием пользователя не определён имеющимися требованиями. Для этого перехода ожидание неизвестно; требуется решение владельца требований.
