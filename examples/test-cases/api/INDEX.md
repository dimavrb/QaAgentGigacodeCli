# Примеры API

Выбери один файл по цели текущей проверки. Не загружай все примеры. Контракты, HTTP-коды, тексты, диапазоны и данные здесь учебные: замени их требованиями приложения.

| Цель | Пример |
| --- | --- |
| Создание ресурса, позитивный сценарий | [create.json](create.json) |
| Обязательные поля, ошибка запроса и отсутствие записи | [validation.json](validation.json) |
| Выход за допустимый диапазон | [boundary.json](boundary.json) |
| Доступ к чужому ресурсу | [permissions.json](permissions.json) |
| Пагинация и порядок элементов | [pagination.json](pagination.json) |

Если точного совпадения нет, используй ближайший пример оформления, не добавляя его сценарий в покрытие. Второй пример читай только для другого существенного аспекта, который не показан первым.
