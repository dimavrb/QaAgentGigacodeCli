# HTML-план с переходами к требованиям

```bash
python3 examples/test-plan-html/build_demo.py --output-dir dist/previews/test-plan-html-demo
```

Откройте result.plan.html из новой папки. У EX-UI-001 две ссылки на требования,
у EX-UI-005 — одна. Клик ведёт к исходному тексту требования, обратная ссылка —
к кейсу. Есть поиск по ID/названию, подробности и карта покрытия.

Демо использует стандартную регистрацию, отдельный fixture-отзыв и принятие;
не запускает GIGACODE и продуктовые проверки. История предыдущих запусков
не перезаписывается. Полный протокол — [TEST_PLAN_HTML.md](../../docs/TEST_PLAN_HTML.md).
