# Задача: не придумать права

Подготовь тест-план и каталог, без выполнения продукта. Единственный источник требований — этот файл:

- R-1: поиск по точному номеру своего заказа возвращает этот заказ; номер другого заказа не подставляется.
- R-2: удаление чужого заказа оператором регулируется матрицей прав, но матрица и ответ владельца требований отсутствуют.

Других источников нет; не ищи матрицу в интернете. Есть данные для поиска, стенд готов. Сохрани готовую независимую часть. Укажи конкретный вопрос по R-2, затронутое покрытие и источник, который нужен для продолжения. Ответ пользователя пока не получен. Не закрывай весь план как готовый.
