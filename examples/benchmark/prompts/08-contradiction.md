# Противоречащие источники прав

Для одной сборки 42 получены два источника одинакового неподтверждённого приоритета: criterion.md#R-1 «менеджер может удалять чужой черновик», security.md#R-1 «менеджер не может удалять чужие заказы». Правило приоритета не предоставлено. Независимое R-2: поиск собственного заказа по точному ID возвращает этот заказ. Сервис/данные не запускались.

Определи готовые и неизвестные части, задай один конкретный вопрос разрешения противоречия, свяжи его с R-1. Дай следующий шаг по R-2. Не выбирай сам более удобный документ и не задавай выдуманное HTTP ожидание.
