# Ревью вывода по версии строки

Оцени только содержание TC-NO-WRITE, без процедурной приёмки реальных файлов.
Источник synth-contract rev-4:
R-1 — ответ возвращает сохранённый ключ; R-2 — обработчик не предпринимает попыток
обратной записи ключа, даже если операция затронет ноль строк или откатится.
Оба критерия обязательны.

Авторский кейс и предоставленная учебная запись:
1. Подготовка завершена commit. База и контроль читаются свежо с primary,
   между ними нет сторонних изменений, обработка завершилась.
2. Ответ на EVT-17 вернул сохранённый ключ, R-1 подтверждён.
3. stored_key, xmin и ctid остались прежними. Автор записал: «R-2 пройден,
   UPDATE вообще не вызывался; весь кейс passed».
4. В доступном логе есть начало поиска по EVT-17, сообщений о записи нет.
   Детализация и полнота лога неизвестны.
5. Для альтернативного наблюдения автор предлагает: если ctid изменится,
   это докажет пересчёт именно stored_key.

Верни замечания с критичностью и явным булевым blocking, итог для кейса, что уже
доказано и какое наблюдение нужно для оставшегося критерия. Новые действия не
выполняй; собственный прогон и причину поведения продукта не утверждай.
