# Неполная карта влияния

Учебный каталог содержит TC-A, TC-B, TC-C. Требуется выбрать регресс для base=v1,
target=v2. Снимок изменений подтверждённо содержит C-1 и C-2.
C-1 связан с модулем M1, TC-A подтверждённо его покрывает. Для C-2 связь с компонентами
неизвестна. У TC-B mapping_status=unknown, TC-C связан с M3. История прошлых дефектов
недоступна (completeness.history=false), политика требует TC-C при любом изменении.
В source requirements rev-5 у C-2 есть новое правило, для которого кейс ещё не создан.
Измерены duration(TC-A)=2 с, duration(TC-B)=null, duration(TC-C)=3 с.

Коллега предлагает исполнить только TC-A, исключить TC-B/TC-C и заявить ускорение
«в пять раз». Оцени выбор и нужный fallback, судьбу каждого ID и пробел нового
правила. Дай допустимый вывод по длительности. Не придумывай связи, историю,
замеры wall-clock или новый ID готового покрытия. Селектор/продукт не запускай.
