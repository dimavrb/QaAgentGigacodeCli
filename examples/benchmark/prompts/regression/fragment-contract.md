# Граница точного сравнения и фрагмента

Оцени содержание TC-LABEL по полному учебному контракту R-1 rev-2:
GET /labels/17 возвращает HTTP 200 и JSON с полем label типа string, содержащим
подстроку "AB" с учётом регистра. Прочие символы label и дополнительные поля JSON
не нормируются. fixture label_17 создаёт доступный объект 17 и даёт клиенту base URL.

Предложенный кейс: выполнить GET /labels/17. Ожидать HTTP 200, строковый label,
для которого contains("AB") = true. В «Тест-дата» request и response со scope=fragment;
пример body {"label":"AB-17"}. Пример иллюстративный, не замена expected_result.

Автор просит усилить ожидание до label = "AB-17" и точного совпадения всего JSON,
сославшись на правило о сравнении полных значений. Дай решение и допустимые
положительный/отрицательный мысленные контрпримеры. Нормализацию не выдумывай,
продукт не запускай, весь кейс исполнявшимся не называй.
