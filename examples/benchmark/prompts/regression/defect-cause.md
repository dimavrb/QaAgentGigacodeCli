# Подтверждённый факт и неизвестная причина

Учебный источник R-1 rev-4: покупатель не имеет доступа к GET /admin/users,
должен получить HTTP 403 без данных пользователей. Первичный сохранённый ответ
request=req-17 на build=v2: роль buyer, HTTP 200, JSON {"users":["U-9"]}.
Принадлежность роли, окружения и ответа подтверждена доверенной квитанцией E-1.

Статическое наблюдение E-2: в исходниках build=v1 отсутствует проверка роли.
Соответствие этих исходников развёрнутому v2 неизвестно. Других runtime-наблюдений
и кода v2 нет. Предлагаемый вывод: «На v2 подтверждён дефект; причина точно в
отсутствии проверки роли в этом фрагменте E-2; блокировать подтверждение до кода».

Дай вердикт по факту и отдельно по причине. Сохрани ключи воспроизведения,
первичные доказательства, ограничения и адресный следующий шаг. Не проводи новый
прогон, не выдавай статический фрагмент v1 за путь исполнения v2.
