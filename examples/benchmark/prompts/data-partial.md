Синтетические первичные записи: назначены TC-OWN и TC-PAY. Для TC-OWN запись O-1 создана текущей попыткой, владелец A и видимость для A проверены. Для TC-PAY запись O-2 создана текущей попыткой, но ожидаемая связь с платежом ещё не проверена: чтение завершилось timeout. Начало cleanup зависимых проверок не разрешено: TC-OWN ещё предстоит выполнить. В общей организации есть старый заказ O-OTHER другого worker. Предложи передачу данных и план восстановления/очистки. Факты из записей можно цитировать, инструменты недоступны.
