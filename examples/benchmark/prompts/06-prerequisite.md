# Полезная проверка без второго аккаунта

Учебный источник R-1: пользователь A может читать собственный ORDER-A, а пользователь B может читать собственный ORDER-B. R-2: A получает 403 без полей заказа при чтении ORDER-B. Заказы можно подготовить отдельно в разрешённой тестовой среде. Сейчас подтверждены только аккаунт A и доступ к его UI; аккаунта B, ORDER-B и API доступа нет. Никаких запусков ещё не было.

Подготовь два сценария TC-OWN и TC-FOREIGN с проверяемыми ожиданиями. Для каждого отдельно укажи готовность проектирования и исполнения. Объясни, что можно продолжать сейчас и что нужно получить; нельзя просить реальную среду ради этого учебного ответа.
