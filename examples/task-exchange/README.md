# Сохранённый пример передачи через реестр

assignment.json, result.json и assessments.json показывают прежний синтетический
протокол передачи без пунктов админгайда. Они сохранены для аудита и проверки
совместимости; реальный стенд, GIGACODE и внешние системы здесь не проверялись.
Структурная валидность и self_review не доказывают готовность стенда.

Новый исполняемый пример передачи находится в
[environment-readiness](../environment-readiness/README.md): builder создаёт
отдельную временную директорию, полный снимок учебного гайда и наблюдения каждого
пункта. Новое назначение qa-test-env-configurator не может принять этот старый
environment_ready без нового environment_assignment и подтверждений.

Существующие реестры и результаты не переписывайте ради прохождения нового
протокола. Для новой работы используйте новые ID и пути. Правила владения,
атомарной передачи, submit/review и повторного использования доказательств —
[TASK_EXCHANGE.md](../../docs/TASK_EXCHANGE.md). ack подтверждает обработку
уведомления, но не принимает результат; prepare резервирует передачу, но не
доказывает запуск исполнителя.
