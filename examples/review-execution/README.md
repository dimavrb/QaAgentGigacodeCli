# Синтетическое ревью с исполнением

build_demo.py готовит план одного автора и независимого runtime reviewer. Его MCP
backend запускает именно test_filter.py целевого автора, без произвольного shell.
Штатный запуск, контролируемая чужая запись и восстановленный штатный запуск
получают отдельные свежие OBS-квитанции. После исправления все проверки повторяются
для нового target. Формат и команды — [REVIEW_EXECUTION.md](../../docs/REVIEW_EXECUTION.md).

Артефакты подтверждают работу процессов, шлюза и барьеров приёмки. Качество живого
GIGACODE, реальный MCP приложения и продукт не проверяются этим примером.
