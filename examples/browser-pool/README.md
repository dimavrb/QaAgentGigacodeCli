# Учебный пул Playwright

pool.json содержит три синтетических имени серверов и isolated-режим. Это не настройка MCP: сопоставьте реальные имена и режимы. Никаких процессов/браузеров пример не создаёт. Порядок — docs/BROWSER_PROFILES.md.

Для трёх постоянных профилей используйте persistent-pool.json: сначала замените **все** REPLACE_WITH_ACTUAL_PATH реальными абсолютными userDataDir из MCP-настроек. Режим persistent и существующие каталоги/авторизация сохраняются. Шаблон без замены путей не принимается реестром; реальные каталоги этот пример не создаёт и не удаляет.

```bash
python3 -m unittest discover -s tests -p test_browser_pool.py -v
```

18 тестов проверяют начальный карантин и принятие; одновременный запрос шести процессов на один профиль; три владельца и очередь; повтор назначения; heartbeat/TTL без ложного освобождения; закрытие контекста вместо вкладки; ошибочные/старые доказательства; timeout/recovery; защиту от прежнего lease; retry после потерянного CLI-ответа; запрет сброса реестра и свободного статуса без подтверждения очистки; одинаковые persistent userDataDir, включая symlink.

Тестовые доказательства синтетические и не переносятся в рабочий реестр. Фактическое закрытие профиля проверяется с подключённым MCP отдельно.
